# 🐺 Veiseh Finder

**داشبورد جستجوی تجهیزات سنگین و ماشین‌های ساختمانی**

جستجو و مقایسه قیمت دستگاه‌ها در تمام پلتفرم‌ها (Divar، Sheypoor، اینستاگرام) از یک جا!

---

## **ویژگی‌ها** ✨

✅ **جستجوی اعلام:** بولدوزر، حفار، لودر، ماشین سنگین و...
✅ **فیلتر قیمتی:** محدوده قیمت مورد نظر انتخاب کن
✅ **علاقه‌مندی‌ها:** ذخیره آگهی‌های مورد علاقه
✅ **چند منبع:** Divar، Sheypoor، اینستاگرام
✅ **موبایل-فرست:** طراحی بهینه برای موبایل
✅ **نصب به عنوان اپ:** PWA - نصب در Home Screen

---

## **نحوه نصب** 📱

### **اندروید (Chrome):**
1. لینک را در Chrome باز کن
2. **⋮** (منوی سه نقطه) → **"Install app"**
3. **Install** کلیک کن

### **آیفون (Safari):**
1. لینک را در Safari باز کن
2. **Share** (پایین) → **"Add to Home Screen"**
3. **Add** کلیک کن

---

## **Development** 💻

### **Requirements:**
- Node.js 18+
- npm یا yarn

### **نصب:**
```bash
git clone https://github.com/[your-username]/veiseh-finder.git
cd veiseh-finder
npm install
```

### **Development Server:**
```bash
npm run dev
# http://localhost:3000
```

### **Build:**
```bash
npm run build
npm start
```

---

## **Deployment** 🚀

### **Vercel (رایگان):**

1. **GitHub account** بساز: https://github.com/signup
2. **Repository** بساز و کد رو upload کن
3. **Vercel** برو: https://vercel.com
4. **"Import Project"** → GitHub repository انتخاب کن
5. **Deploy** کلیک کن

✅ URL شما آماده میشه!
